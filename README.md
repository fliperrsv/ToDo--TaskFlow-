# TaskFlow 3.0 – умный менеджер задач

[![GitHub Pages](https://img.shields.io/badge/Демо-taskflow-ff6b4a?style=flat-square&logo=github)](https://fliperrsv.github.io/taskflow/)

**TaskFlow 3.0** – это современное веб-приложение для управления задачами с поддержкой категорий, приоритетов, дедлайнов, поиска, тёмной темы и Drag & Drop.

🔗 **Живое демо:** [https://fliperrsv.github.io/taskflow/](https://fliperrsv.github.io/taskflow/)

---

## 📦 Функционал

- ✅ Добавление, удаление, выполнение задач
- ✅ Категории (Работа, Личное, Учёба, Другое)
- ✅ Приоритеты (Высокий, Средний, Низкий)
- ✅ Дедлайны с подсветкой просроченных
- ✅ Поиск по задачам
- ✅ Фильтрация (Все / Активные / Выполненные)
- ✅ Drag & Drop для изменения порядка
- ✅ Экспорт / импорт данных (JSON)
- ✅ Тёмная / светлая тема (запоминается)
- ✅ Статистика (всего, выполнено, активно)
- ✅ Адаптивный дизайн для всех устройств

---

## 🛠 Технологии

- **HTML5** – семантическая разметка
- **CSS3** – адаптив, тёмная тема, анимации
- **JavaScript (ES6+)** – работа с DOM, LocalStorage, Drag & Drop, экспорт/импорт

---

## 🚀 Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/fliperrsv/taskflow.git
   cd taskflow
```

2. Откройте файл index.html в браузере (или используйте локальный сервер).
3. Всё готово! Задачи сохраняются в localStorage.
